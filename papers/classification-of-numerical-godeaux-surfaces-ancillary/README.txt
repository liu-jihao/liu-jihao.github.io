# Ancillary files: computer-algebra scripts

This package contains the computer-algebra scripts, together with their outputs, behind the computational statements of Section 15 of the paper "Classification of numerical Godeaux surfaces" by Jihao Liu, Wenfei Liu, and Lei Zhang.

## Contents

- `plan/`: the count of the coefficients of the multiplication table μ.
- `read/`: normal forms of the nets of [CCO94, Proposition 5.1].
- `cases/`: the computations for the statements of the section, one folder for each family:
  - `cases/nets/`: the special nets, the net changes and the normal forms (common definitions in `nets_common.sing`);
  - `cases/n1c1/`: type (I,1);
  - `cases/n1c0/`: type (I,0);
  - `cases/n2/`: types (II,1) (files `n2c1_*`) and (II,0) (files `n2c0_*`), common definitions in `n2_defs.sing`;
  - `cases/n3/`: type (III,1).
- `independent_checks/`: a second implementation of the same computations, written separately from `cases/`, with the same folder structure (`nets`, `n1c1`, `n1c0`, `n2`, `n3`; common definitions in `nets/vlib.sing`, `n1c0/vring.sing` and `n1c0/vbuild.sing`).

Each script `<name>.sing` that is run comes with its output `out_<name>.txt` in the same folder, with two exceptions in naming: in `cases/n1c1/` the output of `n1c1_<X>.sing` is `out_<X>.txt` (for example `out_B_elim.txt`), and in `read/` the output is `cco94_normal_forms.out`. The files `*.sing` without an output are included by other scripts (common definitions and generated code), except `independent_checks/n1c0/v3_gb.sing` and `independent_checks/n3/v_nf_debug.sing`, whose outputs are not included and which the paper does not use. Some scripts also write data files that later scripts of the same folder read: lists of equations, substitutions and free unknowns (`*.txt`), generated Singular code (for example `cases/n3/n3_final.sing`, `independent_checks/n3/v_graph.sing`), and saved Singular states (`*.ssi`). These data files are included, so each script can be run on its own. Where a script reads such a file, it is run after the script that writes it: in `cases/n2`, the `*_build.sing` scripts come before the `*_elim.sing` and `*_global.sing` scripts, which come before the `*_post.sing` scripts; in `cases/n3`, `n3_elim.sing` comes before `n3_checks.sing`, `n3_aux.sing` and `n3_shear.sing`.

The files `*.py` are Python 3 generators: they write some of the `.sing` scripts and data files (for example `cases/n1c1/gen_n1c1.py` writes `n1c1_A_eqs.sing` and `common_n1c1.sing`), or compare and summarize text outputs. They do no algebra beyond bookkeeping. The generated files are included, so the generators need not be run again; running one overwrites the files it writes.

Four files read a file in another folder of the package, by a relative path: `independent_checks/n3/v_compare.sing` and `independent_checks/n3/v_shear.sing` read `cases/n3/n3_final.sing` (and `v_compare.sing` also `cases/n3/n3_free.txt`), `independent_checks/n3/gen_casemap.py` reads `cases/n3/n3_unknowns.txt`, and `independent_checks/n2/vcmp_gen.py` reads `cases/n2/out_n2c1_stage_post.txt`.

## Running the scripts

All scripts are for Singular 4.4.1 [DGPS25]. Each script is run from its own folder, as

```
cd cases/n1c1
Singular -q n1c1_B_elim.sing
```

since the files it includes (`< "..."`) and the data files it reads are given by paths relative to that folder. The Python generators are run in the same way, from their own folder, with `python3 <script>`.

## Exactness

All computations are exact, over Q, over Q(i), or over a rational function field over Q, except those marked mod p. The following are computations over the prime field F_p (p = 32003, or p = 1000003 in `V2_points.sing`) and are not used in the paper:

- the scripts `cases/n1c1/n1c1_E_modp.sing`, `cases/n2/n2c1_stage_modp.sing` (generated by `cases/n2/gen_n2_modp.py`) and `independent_checks/n1c0/v9_jac_modp.sing`;
- the parts marked mod p of `cases/n1c0/s6.sing` (Jacobian ranks), `cases/n3/n3_checks.sing` (part (d), Jacobian ranks), `independent_checks/n1c1/V2_points.sing` (part (1)) and `independent_checks/n3/v_checks.sing` (part B). The other parts of these four scripts are exact.

## Names in the scripts

The scripts use the following names for the objects of the section: `D` is δ; `b(1)`, …, `b(12)` are η_1, …, η_12; `g(1)`, …, `g(10)` are g_1, …, g_10; the coefficients of μ are `l(1..371)`, `L(1..371)`, `lam(1..371)` or `x(1..371)`, depending on the folder; the presentation matrix is `A` (in some scripts with a suffix); the nets α_I(δ), α_II, α_III are `N1(D)`, `N2`, `N3`; κ_1, κ_2 are `c1`, `c2`; the parameter c of the types (I,c), (II,c), (III,c) is `c`. The first lines of each script describe what it computes.
